# 000017-010-infra-codex-karpathy-validation

## Purpose
Codex Karpathy guideline integration source changes를 generated plugin package에 sync하고, repository validation과 install metadata checks로 batch 완료를 증명한다.

## Scope
- `bash scripts/sync-codex-plugin.sh` 실행
- `bash scripts/validate.sh` 실행
- Codex skill/agent install list checks 실행
- final diff가 scope boundary를 지키는지 확인
- generated plugin package diff가 source skill 변경과 대응되는지 확인

## Spec Reference

### Primary Sources
- `docs/ywc-plans/codex-karpathy-guideline-integration.md#fr-7-sync-and-validate` — sync/validation 요구사항
- `docs/ywc-plans/codex-karpathy-guideline-integration.md#acceptance-criteria` — AC10, AC11, AC12 검증 기준
- `codex/AGENTS.md#build-test-and-development-commands` — Codex source/generated package rules

### Summary
이 task는 content update task가 모두 merge된 뒤에만 실행하는 hard gate이다. Codex skill source는 `codex/skills`이고 plugin package는 generated output이므로, sync script를 통해서만 갱신한다. Validation, install list, targeted rg, scope diff checks를 모두 통과해야 batch가 complete이다.

### Out of Scope (from spec)
- Source skill/agent content edits — handled by Phase `000016` tasks
- Manual edits to `plugins/ywc-agent-toolkit/skills/**` — explicitly out of scope
- Claude Code changes — out of scope for this spec

- No source files should be manually edited in this task except generated sync output

## Notes
- This task must not start until all Phase `000016` tasks have merged.
- If validation fails because plugin package is stale, rerun sync and validation.
- If validation fails for a real source issue, return to the owning Phase `000016` task instead of patching generated output.
