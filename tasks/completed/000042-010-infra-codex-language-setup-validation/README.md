# 000042-010-infra-codex-language-setup-validation

## Purpose

Codex language setup feature 전체를 sync 및 validation으로 닫는다. Source edits가 모두 끝난 뒤 generated marketplace package를 필요한 경우 동기화하고, repository validation과 targeted checks를 실행한다.

## Scope

- Phase `000041` 전체 완료 후 실행하는 hard gate.
- `bash scripts/sync-codex-plugin.sh` 실행이 필요한지 확인하고 필요하면 실행.
- `bash scripts/validate.sh`, `bash scripts/install.sh --list --codex`, targeted `rg` checks 실행.
- 결함 발견 시 원인 task로 회귀 보고.

## Spec Reference

### Primary Sources

- `docs/ywc-plans/codex-ywc-language-setup.md` — AC10, Dependencies, Verification Commands, Implementation Plan.

### Summary

이 feature 는 Codex source skill package와 generated marketplace package가 둘 다 최신이어야 완료된다. Validation hard gate는 모든 source edit task가 끝난 뒤에만 의미가 있다. 이 task 는 기능을 직접 구현하지 않고, sync/validation과 final evidence collection을 담당한다.

### Out of Scope (from spec)

- Source skill behavior edits — Phase `000041` tasks.
- Claude Code parity.
- Actual application code changes.
