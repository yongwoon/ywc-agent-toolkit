# yw-000035-020-domain-quality-gate-spec-template

## Purpose
Give `ywc-plan`'s claude-code spec template a place to declare a per-spec Quality Gate Contract and Module Boundaries, so future specs generated by this toolkit can opt into CRAP/Mutation gates or explicitly opt out.

## Scope
Insert net-new `## Quality Gate Contract` and `## Module Boundaries` sections into `claude-code/skills/ywc-plan/references/spec-template.md` only, placed immediately after `## Existing Constraints Touched` and before `## Acceptance Criteria`.

## Spec Reference
### Primary Sources
- `docs/ywc-plans/20260910-quality-gate-contract-port.md#fr-2-ywc-plan-spec-templatemd--author-net-new-quality-gate-contract--module-boundaries-sections` — FR-2 (claude-code half only)
- `docs/ywc-plans/20260910-quality-gate-contract-port.md#acceptance-criteria` — AC2.5, AC11

### Summary
Both new sections are per-spec declarations: `## Quality Gate Contract` states the CRAP/Mutation thresholds this spec's tasks must meet, or `N/A — no quality gate contract`; `## Module Boundaries` states a new module's public interface and forbidden edges, or `N/A — no code module introduced`. Both link `claude-code/skills/references/quality-gates.md` (created by `yw-000035-010`) via an `> **Action required**: Read [...]` pointer rather than restating thresholds inline. Per the spec's Edge Cases, FR-2 has no ordering dependency on FR-1 — it may land before or after `yw-000035-010` exists.

**Unverified assumption carried into this task**: the port spec's Existing Constraints Touched table implies the codex-side `spec-template.md` was already updated for this heading pair by the prior `yw-000032-010-domain-plan-scaffold-quality-declaration` codex task. Re-verification during this task's investigation found `codex/skills/ywc-plan/references/spec-template.md` still has **no** `## Quality Gate Contract` or `## Module Boundaries` heading (confirmed via `grep -n "^## "`). This is a residual gap in the prior codex batch, not something this task fixes — this task's Ownership is claude-code-only. Flag to the user/executor as a concern, not a blocker.
