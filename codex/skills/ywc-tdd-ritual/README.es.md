# ywc-tdd-ritual

Aplica el ciclo RED -> GREEN -> REFACTOR antes de escribir código de producción para features, bugs o cambios de comportamiento.

Exige observar primero el test fallando para evitar tests escritos solo después del hecho.

## Contrato de comentarios de autoría

Define el public test seam existente y sus catches/misses. Completa RED/GREEN/REFACTOR de un comportamiento antes del siguiente; si falta un seam adecuado, conserva la reproducción y plantea la decisión de interfaz.
