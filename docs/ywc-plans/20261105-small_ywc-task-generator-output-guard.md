# Plan: ywc-task-generator 출력 경로 및 완료 가드 보강

> Status: Ready for implementation
> Scale: Small
> Created: 2026-11-05

## Goal

`ywc-task-generator`가 spec 위치를 출력 위치로 혼동하지 않도록 출력 경로 우선순위를 명시하고, 승인된 preview를 실제로 소비해 task와 dependency graph를 쓴 경우에만 완료로 보고하도록 보강한다. `docs/ywc-plans/<spec>.md` 입력에서 `--tasks-dir` 생략 시 저장소 루트 `tasks/`가 선택되는 회귀 시나리오를 추가한다.

기존 persisted preview, digest, 승인 및 path containment 경계는 유지한다. 승인 전에는 task 디렉터리나 그래프를 생성하지 않으며, 승인 누락 시 필요한 preview 승인 정보만 안내한다.

## Out of Scope

- Claude Code용 `ywc-task-generator` 변경은 포함하지 않는다.
- Task decomposition, graph schema, preview identity/digest 계약 변경은 포함하지 않는다.
- 사용자의 `~/.codex/skills` 설치본을 직접 수정하거나 자동 설치하지 않는다.

## Files to Touch

| File | Change Type | Reason |
|---|---|---|
| `codex/skills/ywc-task-generator/SKILL.md` | Modify | `--spec` 경로와 무관하게 repo-root 기준으로 기본 `tasks/`를 결정하고, 실제 산출물 검증 후 완료하도록 절차를 명확히 한다. |
| `codex/skills/ywc-task-generator/evals/evals.json` | Modify | spec이 `docs/ywc-plans/`에 있을 때 출력 경로, 승인 전 무쓰기, 승인 후 artifact 존재를 함께 검증하는 회귀 eval을 추가한다. |
| `scripts/run-codex-skill-contract-evals.sh` | Modify | 새 output-guard eval과 skill 규칙이 contract runner에서 필수임을 확인한다. |
| `plugins/ywc-agent-toolkit/skills/ywc-task-generator/` | Generated by sync | marketplace 배포본을 source skill과 일치시킨다. 직접 편집하지 않는다. |

`agents/openai.yaml`은 skill의 목적과 interface가 바뀌지 않으므로 내용 변경 대상이 아니며, 구현 시 정합성만 확인한다.

## Implementation Steps

- [ ] `scripts/run-codex-skill-contract-evals.sh`에 output-guard 회귀 계약 검사를 추가한 뒤 기존 source/eval으로 실행해 실패를 확인한다.
      -> verify: runner가 `ywc-task-generator`의 경로 규칙과 output-guard eval 부재를 구체적으로 보고하며 nonzero로 종료한다.
- [ ] RED에 이어 `evals/evals.json`에 과거 실패를 대표하는 회귀 시나리오를 추가한다. spec이 `docs/ywc-plans/`에 있고 기본 output을 사용할 때 루트 `tasks/`를 고르며, 승인 없는 preview에서는 task 파일을 쓰지 않고, matching digest 승인 후에만 산출물을 기록하도록 기대값을 정한다.
      -> verify: JSON parse 성공; eval이 출력 경로, 승인 경계, task 디렉터리 및 graph 존재 조건을 각각 확인한다.
- [ ] `codex/skills/ywc-task-generator/SKILL.md`의 output resolution 절차를 보강한다. `--tasks-dir`가 생략되면 저장소 루트를 기준으로 `tasks/`를 선택하고, spec의 부모 디렉터리를 출력 경로로 추론하지 않도록 명시한다. preview/승인 절차는 유지하며, 승인 전 task 경로 생성 금지와 승인 소비 후 task 파일 및 `dependency-graph.md` 존재 확인을 완료 조건으로 둔다.
      -> verify: `--spec docs/ywc-plans/example.md` + 기본 경로 예시가 `tasks/`를 가리키고, 승인 전 쓰기 금지 및 승인 후 artifact 확인 문구가 skill에 존재한다.
- [ ] Source-first 흐름으로 marketplace bundle을 동기화하고 skill metadata 및 locale 구조를 검토한다.
      -> verify: `bash scripts/sync-codex-plugin.sh` 후 source와 generated package가 일치하고, `agents/openai.yaml`의 display name/description/default prompt가 기존 목적과 일치한다.
- [ ] 회귀 eval과 bundle 검증을 실행한다.
      -> verify: Verification 명령이 모두 exit 0이다.

## Risks and Rollback

| Risk | Likelihood | Mitigation / Rollback |
|---|---|---|
| Path 설명이 persisted preview의 repository-relative 경로나 사용자 지정 `--tasks-dir` 의미를 바꿀 수 있다. | Medium | 기본값과 명시적 override를 분리해 문서화하고 기존 preview path/digest eval을 유지한다. 문제가 생기면 source SKILL/eval 변경을 되돌린 뒤 `bash scripts/sync-codex-plugin.sh`로 generated package를 복구한다. |

## Acceptance Criteria

- [ ] spec이 `docs/ywc-plans/`에 있어도 기본 task output은 저장소 루트의 `tasks/`로 해석된다.
- [ ] 승인 전 preview 단계에서 task 디렉터리나 dependency graph가 생성되지 않는다.
- [ ] matching preview 승인 이후 task 파일과 `tasks/dependency-graph.md`가 실제로 존재해야만 완료를 보고한다.
- [ ] 사용자에게 mode, initials, 또는 출력 경로를 이미 확인받았으면 같은 정보를 다시 요구하지 않는다.
- [ ] Verification 명령이 모두 통과하고 generated plugin package가 source와 일치한다.
