# Issue #215 — mechanical bug batch

> Scale: Medium
> Source: https://github.com/yongwoon/ywc-agent-toolkit/issues/215 (follow-ups deferred from #214)

## Purpose

Fix the nine correctness defects from issue #215 that need no design decision. Each one is
present on `main` (verified 2026-11-07) and either makes a documented command fail, lets a
guard miss its target, or leaves a test that cannot fail on the platform where it matters.

**Why**: these were deferred from #214 only to keep that release bounded; several are
fail-open (a PR-review worktree force-removed, a committed `.env` or a single-quoted password
reported clean).

## Scope

1. `ywc-parallel-executor` runs `update-state.py` with `python3`, not `bash`.
2. PR-review worktree basename accepted as `pr-<N>` **or** `worktree-pr-<N>`; prune pointer and
   audit label corrected.
3. `scan-secrets.sh` password pattern matches single-quoted values.
4. `scan-secrets.sh` match preview no longer pipes through `head`.
5. `scan-secrets.sh --committed` flags dangerous file names in the committed range.
6. `test-scan-secrets.sh` UTF-8 cases use an installed UTF-8 locale.
7. `ls-remote` existence checks compare the ref name exactly.
8. CI shellchecks `codex/skills`.
9. `claude-code/agents/README*.md` list `ywc-cloud-engineer`.

## Out of Scope

Every other item in #215, including: new secret patterns (`sk-ant-` etc.), `--staged`
performance, the `+x` combined-diff form (P2-b), merge-dependabot items, `ywc-auth-implement`
task split, atomic integration-branch ownership (the Major half of item 7), retro-lens read
scope, the `wave-int/<N>` `ls-remote --heads` tail match in
`ywc-parallel-executor/references/wave-integration-branch.md:31`, and fixing the pre-existing
shellcheck findings themselves (they are carved out with `ignore_paths`).

## Functional Requirements

- **FR-1** Replace `bash` with `python3` at the five `update-state.py` call sites.
- **FR-2** In `ywc-parallel-executor/SKILL.md:120`, match basename `pr-<N>` or `worktree-pr-<N>`
  and point cleanup at `ywc-worktrees --mode prune --task-name pr-<N> --branch <H> --keep-branch`
  (as `ywc-handle-pr-reviews` Step 9 reports). In `ywc-handle-pr-reviews/SKILL.md:306`, accept
  both basenames and say the pre-flight audit reports it under `DRIFT`.
- **FR-3** Password pattern matches a real apostrophe. The array element is written in double
  quotes so the `'` needs no escaping: `"password\\s*=\\s*[\"'][^\"']{4,}"` (the old `\x27`
  is not an escape in ERE; the bracket matched `\`, `x`, `2`, `7`).
- **FR-4** Preview uses `sed -n '1,3s/^/  /p'` with no `head`. Add a test whose matching added
  lines exceed 64 KB and expect exit `1` (fails today with 141 → read as BLOCKED). The preview
  stays unmasked on purpose: masking it is a separate #215 item ("The scanner echoes matched
  secret lines to stdout", Low) and is out of scope here.
- **FR-5** Extract the Phase 1 regex into one variable; in `--committed` mode also run
  `git diff --name-only -z --diff-filter=d --no-renames BASE...HEAD | tr '\0' '\n'`
  (failure → exit 2, message names the committed range) and report matches with the same
  `WARN:` block. Update the script header comment (Phase 1 / Phase 3 lines) and the Phase
  description in `ywc-create-pr/SKILL.md` (both platforms) if they say Phase 1 covers only the
  working tree. Test shim gains `failnames` (`diff:*--name-only*` → exit 1, matched before the
  `faildiff` row) with one case expecting `2`; `faildiff` stays as is.
- **FR-6** Tests pick a locale with
  `locale -a 2>/dev/null | grep -iE '^(C|en_US)\.utf-?8$' | sed -n 1p`; if empty, print
  `SKIP: no UTF-8 locale installed` to stderr and skip those cases. Add a case: one untracked
  file with invalid UTF-8 bytes, then a newline, then a secret → `1`.
- **FR-7** Existence checks hold the branch in a variable and run
  `git ls-remote origin "refs/heads/$b" | awk -F'\t' -v r="refs/heads/$b" '$2==r{f=1} END{exit !f}'`
  semantics: `ls-remote` non-zero → stop quoting stderr; exact line found → "exists"; none →
  "absent". The branch is never spliced into the awk program text. Drop the "exit 2" wording at
  both sites. Input boundary: `ywc-worktrees` already allowlists `<branch>` (`SKILL.md:98`);
  `integration/run-<slug>` is safe because `run-<slug>` must pass `^[A-Za-z0-9_-]+$` as the
  `--task-name` before this check runs (`worktree-run.md:27`); no new validation is added.
- **FR-8** Add a `ShellCheck (codex/skills)` step with `ignore_paths` for the ten files above.
  `codex/skills` has no extensionless shebang scripts, so the `*.sh` baseline is complete; CI
  may run a newer shellcheck than 0.11.0 — a CI-only finding is fixed or added to the list in
  the same PR.
- **FR-9** Add `ywc-cloud-engineer` to Tier 3 in all four agent READMEs: every Tier 3 count
  (`6종` / `6 agents` / `6 種` / `6 Tier 3 specialists` / `specialist 6 種`, at README.md:17,27,
  README.en.md:17,27, README.ja.md:17,28, README.ko.md:16) becomes 7, plus the name list, a
  table row noting it is write-capable, and the dispatch list.

## Edge Cases

- `--committed` where the `.env` was added then deleted inside the range: three-dot diff shows
  no file → not flagged (correct: nothing reaches the base).
- Committed `.env` that is also untracked locally: reported twice (status + committed). Accepted.
- `locale -a` absent (minimal container): treated as "no UTF-8 locale" → SKIP line.
- `ls-remote` prints several tail matches: only the exact ref decides; zero exact lines =
  branch absent.
